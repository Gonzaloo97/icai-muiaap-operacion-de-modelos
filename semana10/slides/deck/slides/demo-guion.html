Comandos, desde semana10/modules/10-api-security. Paso 1: uv run fastapi dev examples/api_key_demo.py; curl -i http://127.0.0.1:8000/v1/scores -X POST (401 y WWW-Authenticate: ApiKey); repetir con -H "X-API-Key: demo-front-key" (200). Paso 2: curl -i http://127.0.0.1:8000/v1/admin/usage con la clave de front (403) y con la de ops (200). Enseña también /docs y el botón Authorize. Paso 3: uv run fastapi dev examples/jwt_demo.py; POST /token para emitir un token, GET /v1/me con -H "Authorization: Bearer TOKEN" (200); pega el token en jwt.io para leer el payload; prueba un token caducado o con otra audiencia (401). Paso 4: contra cors_demo.py, curl -i -X OPTIONS con -H "Origin: http://localhost:8501", -H "Access-Control-Request-Method: POST" y -H "Access-Control-Request-Headers: x-api-key"; repetir con un Origin no permitido y señalar que falta Access-Control-Allow-Origin. Paso 5: DEMO_API_KEY=TU_API_KEY uv run fastapi dev examples/limits_demo.py y un bucle de curl (for i in $(seq 1 8); do curl -s -o /dev/null -w "%{http_code}\n" ...; done) hasta ver 429; enseña Retry-After con -i. Paso 6: LOCUST_API_KEY=TU_API_KEY uv run --group load locust -f examples/locustfile.py --headless -u 20 -r 5 -t 1m --host http://127.0.0.1:8000; leer RPS, p95 y el porcentaje de 429 en la tabla final. Los cuerpos JSON exactos de cada endpoint están en el README de examples.
