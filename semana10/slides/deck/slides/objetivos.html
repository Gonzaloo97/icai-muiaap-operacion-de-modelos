Cuatro objetivos que mapean a los bloques: identificar (bloque 1), autorizar (bloque 2), limitar (bloque 4, más CORS del bloque 3 como límite del navegador) y configurar (bloque 4). Resultado práctico: la Wine Quality API 2.0.0 con API key, scopes, rate limiting, CORS desde configuración, contrato regenerado y un informe de carga de Locust. Entregable del roadmap para S10: API protegida, con validación de API key y controles de consumo. Aviso honesto: esto es seguridad mínima de producción, no una auditoría; en empresa se suma un gateway, un proveedor de identidad y revisión de seguridad.
