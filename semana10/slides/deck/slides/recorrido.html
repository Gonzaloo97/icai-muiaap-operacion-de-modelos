Partimos de la solución de S9: la Wine Quality API 1.1.0 con sobre de error único (code, message, fields, request_id), contrato en contracts/openapi.json y suite en verde. Esa suite es la red de seguridad de hoy: añadimos autenticación sin romper lo que ya funcionaba. Al exigir una API key, los clientes anónimos de S7 dejan de funcionar, así que la API pasa a la versión 2.0.0 (cambio mayor). La ruta sigue en /v1 porque los payloads no cambian y el front se actualiza de forma coordinada para enviar X-API-Key. En S11 empaquetaremos esta API en Docker; la configuración por variables de entorno que hacemos hoy es lo que permitirá configurar el contenedor.
