Panorama de mecanismos (5 min); no hay uno mejor, depende de quién llama. API key: un secreto opaco por cliente; perfecto para máquinas (el front de Streamlit, un batch, un partner). Es lo que implementamos en la práctica, por eso va resaltada. JWT Bearer: un token firmado que lleva dentro quién es el usuario y qué puede hacer; caduca solo. OAuth2 / OpenID Connect: el estándar con el que un proveedor de identidad (IdP: Entra ID, Google, Okta, Keycloak) emite esos tokens; es lo que hay detrás de «Iniciar sesión con Microsoft». mTLS: TLS mutuo, el cliente también presenta un certificado; habitual en redes internas, banca y service mesh. Pregunta: ¿qué usaríais para que el front de S5-S6 llame a la API? Una API key de servicio. ¿Y si cada médico o analista tuviera que identificarse? Login con OIDC y JWT. Mencionar que en FastAPI todos se declaran con utilidades de fastapi.security, lo que los documenta en OpenAPI.
