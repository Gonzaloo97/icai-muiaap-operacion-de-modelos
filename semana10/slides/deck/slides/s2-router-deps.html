def require_scope(scope: str):
    def check_scope(client: ClientDep) -> Client:
        if scope not in client.scopes:
            raise HTTPException(status_code=403, detail=f"Missing scope: {scope}")
        return client
    return check_scope

scores = APIRouter(prefix="/v1/scores", dependencies=[Depends(require_scope("predict"))])

Fragmento literal de examples/api_key_demo.py (5 min). require_scope es una factoría: recibe el scope y devuelve una dependencia. Esa dependencia depende a su vez de ClientDep, así que FastAPI resuelve la cadena: primero autentica (401), después autoriza (403). Convención de la skill oficial de FastAPI: las dependencias compartidas por todas las rutas de un grupo se declaran en el APIRouter con dependencies=[...], no repetidas en cada ruta; así, una ruta nueva en ese router nace protegida y nadie puede olvidarse de añadir el control. Dentro de la ruta, si necesito saber quién llama (para el rate limit o para logs), vuelvo a pedir ClientDep: FastAPI cachea la dependencia por petición y no autentica dos veces.
