¿Qué puede hacer cada uno?

Bloque 2, 25 minutos: autorización por scopes y JWT. Ya sé quién llama; ahora decido qué puede hacer. Primera mitad (12 min): scopes con API key en examples/api_key_demo.py, los mismos clientes front y ops. Segunda mitad (13 min): JWT Bearer con examples/jwt_demo.py, que se arranca con uv run fastapi dev examples/jwt_demo.py. La práctica usa API key y scopes; JWT se ve en teoría y demo para entender lo que encontraréis en empresa.
