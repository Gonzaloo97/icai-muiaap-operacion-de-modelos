CORS

CORS no protege mi API: protege al usuario del navegador. curl lo ignora.

Idea central del bloque (3 min). El navegador aplica la política del mismo origen: el JavaScript de una web (por ejemplo, una página maliciosa que el usuario visita) no puede leer respuestas de otro origen salvo que ese origen lo permita con cabeceras CORS. Quien se protege es el usuario: evita que una web ajena use su navegador, con sus cookies o su red interna, para leer datos de mi API. Pero curl, Python, Postman o Locust no aplican CORS: si alguien tiene la URL, llama directamente. Pregunta: si configuro CORS solo para http://localhost:8501, ¿puede un script de Python llamar a mi API? Sí; por eso la API key sigue siendo obligatoria. Origen = esquema + host + puerto: http://localhost:8501 y http://localhost:8000 son orígenes distintos.
