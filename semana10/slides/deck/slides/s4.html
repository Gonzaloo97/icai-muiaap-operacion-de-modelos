¿Cuánto y con qué clave?

Bloque 4, 15 minutos: secrets, rate limiting y prueba de carga. Va rápido porque la demo en vivo (pasos 5 y 6) lo enseña en directo. Demo: examples/limits_demo.py, que se arranca con DEMO_API_KEY=TU_API_KEY uv run fastapi dev examples/limits_demo.py (en PowerShell: $env:DEMO_API_KEY="TU_API_KEY"; uv run fastapi dev examples/limits_demo.py), y examples/locustfile.py para la carga. Tres preguntas: ¿dónde viven las claves?, ¿cuántas peticiones acepto por cliente? y ¿cómo se comporta la API cuando la cargo?
