Error típico: devolver JSONResponse(content=model.model_dump()) con un datetime dentro; falla porque json no sabe serializar datetime. mode="json" resuelve el problema. En el workshop, el sobre de error se construye con model_dump(mode="json", exclude_none=True) para que fields solo aparezca en errores de validación.
