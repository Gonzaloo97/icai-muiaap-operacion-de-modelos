Es un test de snapshot del contrato. El script exporta el esquema con sort_keys para que el diff sea estable. Un cambio accidental (renombrar un campo, quitar un status) hace fallar el test y aparece en la revisión del pull request como diff de contracts/openapi.json, que cualquier persona del equipo puede leer sin abrir el código. En S13 este test corre en CI. Extensión opcional para quien termine antes: Schemathesis genera casos automáticamente a partir de OpenAPI.
