Este fixture está en tests/conftest.py del starter. Tres decisiones: create_app() como factoría para inyectar el predictor (nada de estado global); usar with para que se ejecute el lifespan, que es donde se carga el modelo (sin with, app.state.predictor no existe); y raise_server_exceptions=False para ver el 500 que ve el cliente. El test sigue Arrange, Act, Assert y comprueba el status y error.code, no el texto de message.
